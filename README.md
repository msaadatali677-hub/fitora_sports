# 🏋️ FITORA — Sports & Fitness Store

**A Modern Sports & Fitness E-Commerce Frontend Built with HTML, CSS & JavaScript**

FITORA is a modern, responsive sports and fitness storefront designed with a clean **Neumorphism UI**. It provides an interactive shopping experience where users can explore sports products, browse categories, search for equipment, manage a shopping cart, and save their favorite products.

## 🌐 Live Demo

🚀 **Live Website:** [https://fitorasports.vercel.app/](https://fitorasports.vercel.app/)

📂 **GitHub Repository:** [https://github.com/msaadatali677-hub/fitora_sports](https://github.com/msaadatali677-hub/fitora_sports)

## ✨ Features

- 🎨 **Neumorphism UI** — Modern interface with soft shadows, raised surfaces, and inset elements.
- 📱 **Responsive Design** — Optimized layouts for desktop, tablet, and mobile screens.
- 🛍️ **Product Showcase** — Display sports and fitness products with images, prices, ratings, and reviews.
- 🔎 **Live Product Search** — Find products by name or category.
- 🗂️ **Category Filtering** — Browse products by specific sports and fitness categories.
- 🛒 **Interactive Shopping Cart** — Add products, increase or decrease quantities, remove items, and calculate totals.
- ❤️ **Wishlist Functionality** — Save favorite products during the current session.
- 📱 **Mobile Navigation** — Responsive navigation menu for smaller screens.
- 🔔 **Interactive Notifications** — Get feedback when adding products to the cart or updating the wishlist.
- 💰 **PKR Currency Display** — Product prices are displayed in Pakistani rupees.
- 🖼️ **Product Image Fallbacks** — Emoji-based fallbacks when product images fail to load.
- ♿ **Accessibility Enhancements** — Accessible labels and status notifications for key interactive elements.

## 🚀 Getting Started

Follow these steps to run FITORA locally.

### 1. Clone the Repository

```bash
git clone https://github.com/msaadatali677-hub/fitora_sports.git
```

### 2. Navigate to the Project Folder

```bash
cd fitora_sports
```

### 3. Open the Website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No backend, database, package installation, or build process is required for the current frontend demo.

## 🛒 Shopping Experience

Users can:

1. Explore featured sports and fitness products.
2. Search for products by name or category.
3. Filter products using category buttons.
4. Add products to the shopping cart.
5. Adjust product quantities and view the calculated total.
6. Save or remove products from the wishlist.

**Note:** FITORA is a frontend demonstration project. Checkout and payment processing are not connected to a payment provider. The cart and wishlist are maintained in JavaScript memory and reset when the page is reloaded.
